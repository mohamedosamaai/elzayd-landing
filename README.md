# elzayd.com — صفحة هبوط استراتيجية لبيع النطاق

صفحة هبوط فاخرة ومهيأة للتحويل العالي (ملف `index.html` واحد مستقل بالكامل — فائق السرعة وبدون أي build)، مخصصة لبيع نطاق **elzayd.com** مع دعم كامل للغتين (العربية والإنجليزية RTL/LTR).

---

## 🌟 الميزات الجديدة المُضافة
1. **أزرار شراء متعددة ومباشرة:**
   - شراء فوري عبر Afternic مع إبراز خيار التقسيط (~$83/شهرياً).
   - زر محادثة وتفاوض مباشر عبر **واتساب (WhatsApp)** مع رسالة جاهزة.
   - زر بريد إلكتروني رسمي.
2. **نافذة تفاعلية لتقديم عروض الأسعار (Make an Offer Modal):**
   - تتيح للمشتري إدخال اسمه، عرضه المقترح بالدولار، ووسيلة التواصل، مع إمكانية الإرسال بضغطة زر عبر واتساب أو البريد.
3. **زر واتساب عائم (Floating WhatsApp Widget):**
   - موجود دائماً في أسفل الشاشة للوصول السريع للمشترين من الخليج والإمارات.
4. **تهيئة SEO كاملة لنطاق `elzayd.com`:**
   - Canonical URL + Open Graph + Schema.org Product Offer.

## ⚙️ تخصيص وسيلة التواصل ورابط الدفع

### 1. إضافة رقم الواتساب المباشر الخاص بك:
في ملف `index.html`، ابحث عن `https://wa.me/?text=` واستبدلها برقمك الدولي (مثال: `https://wa.me/97150xxxxxxx?text=` أو `https://wa.me/2010xxxxxxx?text=`) في المواضع الثلاثة (زر الهيدر، الزر العائم، وداخل كود الجافاسكريبت للنافذة).

### 2. إضافة رابط Custom Checkout من Afternic:
من لوحة تحكم Afternic اضغط على **Custom Checkout Link** وانسخ الرابط وضعه بدلاً من `https://www.afternic.com/domain/elzayd.com` لتقليل العمولة إلى 15% فقط.
